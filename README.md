# Tesserium Labs website

Source for https://www.tesseriumlabs.com, built with [Astro](https://astro.build) and Tailwind CSS,
deployed to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```

Write a blog post by adding a Markdown file to `src/content/blog/`. See `CLAUDE.md` and
`.claude/skills/` for design and SEO conventions.
